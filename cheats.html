GTA 6 cheat codes — what is actually true

Short answer (checked 19 November 2026): no GTA 6 cheat code has been officially confirmed by Rockstar, and none has been verified in-game by a reliable source yet. Most "full cheat code lists" already online are copied from GTA 5. This page separates what is Confirmed, what is only Reported, and what is fake — and it will be updated the moment real codes are verified.

Confirmed

  • Rockstar has published no cheat codes for GTA 6 — no official list exists.
  • No code is verified yet. The game launched today (19 November 2026); trustworthy in-game verification takes time.
  • Series pattern: in GTA 5, entering cheats disabled trophies/achievements for that play session. Whether GTA 6 does the same is not announced yet.

Reported — not yet verified

Several guide sites report that GTA 6 handles cheats in a new way. Treat everything in this section as Reported: it matches across multiple guide sites, but those sites state they are still confirming the details in-game.

  • Cheats reportedly appear in a Cheats section of the Progress Menu — only after you finish the main story.
  • A total of 61 cheats are reported, each unlocked by a challenge (for example, completing workouts or escaping the police a set number of times).
  • Reported entry method: press Up on the D-pad to open the phone, hold L1 and press R1 (LB + RB on Xbox), then enter a D-pad sequence.
  • One reported example — a $250,000 cheat said to unlock when the story is finished: Up, Right, Down, Left, Up, Left, Down, Right. Unverified — try it only with this warning in mind.
  • Cheats are reported to be story mode only and to block trophies and saving while active.

Fake lists — how to spot them

If a "GTA 6 cheat codes" page shows phone numbers such as 1-999-7246-545-537 (PAINKILLER) or words like LAWYERUP, you are looking at GTA 5's codes with a GTA 6 label pasted on. The same goes for button lists copied from GTA 5 (for example "Right, X, Right, Left, Right, R1…"). Those codes belong to the old game — there is no evidence they do anything in GTA 6.

What to do meanwhile

  • Play the story — if the reports are right, cheats are an end-game reward this time, not a day-one toy.
  • Bookmark this page: the first verified codes will be added here with their source and the date they were confirmed.

FAQ

Does GTA 6 have cheat codes?
Not confirmed. Guide sites report a post-story cheat system with 61 unlockable cheats, but no code has been verified in-game yet (checked 19 November 2026).

Is there a GTA 6 money cheat?
There is no confirmed money cheat. A $250,000 code is reported by guide sites but remains unverified.

Do cheats disable trophies in GTA 6?
Reported, not confirmed. In GTA 5, cheats disabled trophies for the session; guide sites report the same for GTA 6, plus blocked saving while a cheat is active.
